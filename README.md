# 🏡 Houseboat-Demo (ระบบจองแพพักและสั่งอาหารหมูกระทะ)

โปรเจกต์เว็บแอปพลิเคชันสำหรับระบบจองแพพักริมน้ำและบริการสั่งอาหารชุดหมูกระทะ พัฒนาด้วย **PHP พื้นฐาน (Native PHP)** ร่วมกับ **MySQL** และ **Bootstrap 5** โดยได้รับการปรับปรุงโครงสร้างโค้ดใหม่ (Refactored) ให้อ่านง่าย เป็นระเบียบ ปลอดภัยจาก SQL Injection / XSS และเหมาะสำหรับ Junior Developer นำไปศึกษาและพัฒนาต่อได้ง่าย

---

## 🌟 ฟีเจอร์หลักของระบบ (Main Features)

### 1. สำหรับบุคคลทั่วไป (Guest / Anonymous)
- **หน้าหลัก (Home):** แสดงภาพสไลด์บรรยากาศแพพัก ข้อมูลไฮไลท์ และแผนที่ Google Maps
- **ค้นหาห้องพักว่าง (Search Availability):** ค้นหาห้องพักที่ว่างจริงตามวันที่เช็คอิน เช็คเอาท์ และจำนวนผู้เข้าพัก
- **จองห้องพัก (Guest Booking):** กรอกข้อมูลชื่อ เบอร์โทร อีเมล พร้อมตัวเลือกเพิ่มเตียงเสริม (+500 บาท)
- **ชำระเงินมัดจำ (Deposit Payment):** แสดง QR Code และแจ้งโอนเงินมัดจำ 500 บาท พร้อมแบบฟอร์มอัปโหลดสลิป
- **ตรวจสอบสถานะการจอง (Check Booking Status):** ค้นหาและติดตามสถานะการจองด้วยชื่อ-นามสกุล

### 2. สำหรับลูกค้าสมาชิก (Customer Portal)
- **ระบบสมาชิก (Authentication):** สมัครสมาชิกใหม่ และเข้าสู่ระบบ
- **แดชบอร์ดสมาชิก (Member Dashboard):** หน้าต้อนรับ ค้นหาห้องพักว่าง และสรุปจำนวนรายการจอง
- **จองห้องพักรวดเร็ว (Fast Booking):** ระบบดึงข้อมูลชื่อ เบอร์โทร และอีเมลจากบัญชีผู้ใช้ให้อัตโนมัติ
- **สั่งอาหารหมูกระทะ (Mookata Ordering):** เลือกเซ็ตหมูกระทะ (S, M, L) และเลือกวัตถุดิบ/ของทานเล่นเพิ่มเติมใส่ตะกร้า
- **ตะกร้าสินค้า (Cart System):** ปรับจำนวน ลบรายการ คำนวณราคารวม ระบุหมายเลขห้องพัก และเลือกวันรับอาหาร
- **ประวัติการจองของฉัน (My Bookings):** แบ่งแท็บแสดงรายการจองห้องพัก และรายการสั่งอาหารหมูกระทะ พร้อมปุ่มยกเลิกการจอง
- **จัดการโปรไฟล์ (Profile):** ตรวจสอบและแก้ไขข้อมูลส่วนตัว (ชื่อ, เบอร์โทร, อีเมล, รหัสผ่าน)

### 3. สำหรับผู้ดูแลระบบ (Admin Management)
- **แผงควบคุมระบบ (Admin Dashboard):** แสดงการ์ดสถิติห้องพัก ยอดจอง รายการรอตรวจสลิป และยอดขายอาหาร
- **จัดการข้อมูลผู้เข้าพัก (Bookings Management):** ดูรายการจองทั้งหมด (ทั้งสมาชิกและบุคคลทั่วไป), คลิกดูรูปสลิปขยายใหญ่ใน Modal, กดยืนยันการจอง หรือกดยกเลิกการจอง
- **จัดการรายการสั่งอาหาร (Food Orders):** ดูรายการอาหารหมูกระทะตามห้องพักและวันที่รับประทาน สรุปยอดขายรวม
- **จัดการห้องพัก (Rooms CRUD):** ดูรายการห้องพัก, เพิ่มห้องพักใหม่พร้อมอัปโหลดรูป, แก้ไขราคา/รายละเอียด, ลบห้องพัก
- **จัดการวัตถุดิบหมูกระทะ (Ingredients CRUD):** ดูรายการวัตถุดิบ, เพิ่มวัตถุดิบใหม่, แก้ไขราคา/หน่วย, ลบ, และปุ่มสลับสถานะ "มีสินค้า / สินค้าหมด" ในคลิกเดียว

## 💻 วิธีการติดตั้งและรันโปรเจกต์บน Windows ด้วย XAMPP

### สิ่งที่ต้องเตรียม (Prerequisites)
- ติดตั้งโปรแกรม **XAMPP** (รองรับ PHP 8.0 ขึ้นไป) ดาวน์โหลดได้ที่ [Apache Friends](https://www.apachefriends.org/)
- เว็บบราวเซอร์ เช่น Google Chrome, Microsoft Edge, Firefox

---

### ขั้นตอนที่ 1: วางโฟลเดอร์โปรเจกต์ใน htdocs
1. นำโฟลเดอร์โปรเจกต์ `Houseboat-Demo` ไปวางไว้ในไดเรกทอรี `htdocs` ของ XAMPP เช่น:
   ```
   C:\xampp\htdocs\Houseboat-Demo
   ```

### ขั้นตอนที่ 2: เริ่มต้นการทำงานของ XAMPP
1. เปิดโปรแกรม **XAMPP Control Panel**
2. คลิกปุ่ม **Start** ที่โมดูล **Apache**
3. คลิกปุ่ม **Start** ที่โมดูล **MySQL**
4. ตรวจสอบให้แน่ใจว่าทั้งสองโมดูลขึ้นสถานะเป็นแถบสีเขียว

### ขั้นตอนที่ 3: นำเข้าฐานข้อมูล (Import Database)
1. เปิดเว็บบราวเซอร์ ไปที่:
   ```
   http://localhost/phpmyadmin
   ```
2. คลิกที่แท็บ **"Import" (นำเข้า)** บนแถบเมนูด้านบน
3. คลิกปุ่ม **"Choose File" (เลือกไฟล์)** แล้วเลือกไฟล์:
   ```
   C:\xampp\htdocs\Houseboat-Demo\database\houseboat.sql
   ```
4. เลื่อนลงมาด้านล่างสุด แล้วคลิกปุ่ม **"Import" (ดำเนินการ / นำเข้า)**
5. รอสักครู่ ระบบจะสร้างฐานข้อมูล `houseboat` พร้อมทั้งตาราง 9 ตารางและข้อมูลเริ่มต้นให้อัตโนมัติ 100%

### ขั้นตอนที่ 4: ตั้งค่าไฟล์ .env (ถ้าต้องการ)
- โดยค่าเริ่มต้น ระบบจะเชื่อมต่อฐานข้อมูล XAMPP อัตโนมัติ (`localhost`, user: `root`, ไม่มีรหัสผ่าน)
- หากต้องการปรับเปลี่ยนรหัสผ่าน MySQL สามารถคัดลอกไฟล์ `.env.example` เป็น `.env` แล้วแก้ไขข้อมูลตามต้องการได้:
  ```ini
  DB_HOST=localhost
  DB_PORT=3306
  DB_NAME=houseboat
  DB_USER=root
  DB_PASS=
  ```

### ขั้นตอนที่ 5: เริ่มใช้งานเว็บไซต์
เปิดเว็บบราวเซอร์และเข้าสู่ระบบผ่าน URL:
- **หน้าเว็บไซต์หลัก:** [http://localhost/Houseboat-Demo](http://localhost/Houseboat-Demo)
- **เข้าสู่ระบบสมาชิก:** [http://localhost/Houseboat-Demo/login.php](http://localhost/Houseboat-Demo/login.php)
- **เข้าสู่ระบบผู้ดูแลระบบ:** [http://localhost/Houseboat-Demo/admin/login.php](http://localhost/Houseboat-Demo/admin/login.php)

## 🧪 การทดสอบระบบอัตโนมัติ (Automated Tests)
โปรเจกต์นี้มาพร้อมชุดทดสอบอัตโนมัติครอบคลุมการทำงานทุกส่วน สามารถรันเพื่อตรวจสอบความถูกต้องได้ด้วยคำสั่ง:

```bash

```

**ผลลัพธ์การทดสอบ:**
- Helper Functions (XSS escaping `e()`, แปลงวันที่ไทย `thaiDate()`, แปลงราคา `formatPrice()`)

- ระบบจองห้องพักและอัปโหลดสลิปโอนเงิน (Guest & Member Flow)
- ระบบสั่งอาหารหมูกระทะ การคำนวณยอดเงินในตะกร้า และการบันทึกลง `menubill`
- การทำงาน CRUD ของผู้ดูแลระบบ (เพิ่ม/แก้ไข/ลบ ห้องพัก และ วัตถุดิบ)

## 🛡️ สรุปจุดที่มีการปรับปรุงความปลอดภัยและคุณภาพโค้ด

1. **ป้องกัน SQL Injection 100%:** เปลี่ยนคิวรีทั้งหมดที่รับค่าจากผู้ใช้มาใช้ `PDO Prepared Statements` แทนการต่อสตริง SQL
2. **ป้องกัน Cross-Site Scripting (XSS):** ห่อหุ้มทุกจุดที่นำข้อมูลจากผู้ใช้หรือฐานข้อมูลมาแสดงผลด้วยฟังก์ชัน `e()` (`htmlspecialchars`)
3. **แก้ปัญหา Path แตกและไฟล์สูญหาย:**
   - แก้ไขการสะกดผิดจาก `imges/` เป็น `images/` ทำให้รูปภาพ โลโก้ และปก แสดงผลสมบูรณ์
   - สร้างไฟล์ปลายทางที่ขาดหาย เช่น `home.php` และหน้าจัดการอาหาร
   - จัดการโครงสร้าง `require` ผ่าน `__DIR__` และคำนวณ `BASE_URL` อัตโนมัติ ทำให้หมดปัญหา Fatal Error เมื่อย้ายโฟลเดอร์
4. **แก้ปัญหาความปลอดภัยในการอัปโหลดไฟล์:** ตรวจสอบ MIME Type (`image/jpeg`, `image/png`, `image/webp`) และจำกัดขนาดไฟล์ไม่เกิน 5MB
5. **โครงสร้างโค้ดสไตล์ Junior Developer:** โค้ดเขียนตรงไปตรงมา แยกไฟล์ตามหน้าที่ชัดเจน (Config, Functions, Includes, Views) อ่านและทำความเข้าใจได้ง่ายโดยไม่ต้องเรียนรู้ Framework ซับซ้อน
